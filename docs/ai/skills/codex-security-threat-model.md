# Codex 安全威胁建模 Skill

## 用途
基于代码仓库的威胁建模，枚举信任边界、资产、攻击者能力、滥用路径和缓解措施，输出 Markdown 威胁模型。

## 触发条件
用户明确要求对代码库进行威胁建模、枚举威胁/滥用路径或执行 AppSec 威胁建模时触发。

## 工作流程
1. **收集输入**：仓库路径、部署模型、互联网暴露、认证要求
2. **提取系统模型**：识别组件、数据存储、外部集成
3. **推导边界和资产**：信任边界、资产清单（数据、凭证、模型、配置）
4. **枚举威胁**：按攻击者目标分类，关联受影响的资产
5. **优先级排序**：定性可能性和影响分析
6. **验证假设**：与服务所有者确认关键假设
7. **推荐缓解措施**：结合代码证据的具体建议
8. **质量检查**：确认所有入口点和信任边界已覆盖

## 输出格式
- 文件命名：`<仓库名>-threat-model.md`
- 包含：系统模型、信任边界、资产清单、威胁列表、优先级矩阵、缓解措施

- 仅基于仓库证据，不臆测组件
- 假设必须显式声明
- 输出简洁、基于证据、可审查
