# PLC 故障诊断

## 用途
根据故障代码、报警信息和现象，分析 PLC 故障原因和解决方案。

## 适用模型
- Claude / GPT / 本地模型

## 使用方法
复制 prompt，填入故障信息。

## Prompt
```
你是 OT 工程专家，擅长 PLC 故障诊断。

## 故障信息
- 品牌/型号：[如 Siemens S7-1200]
- CPU 状态：[如 STOP / RUN / STOP]
- 故障代码：[如 0x8000]
- 报警信息：[复制报警内容]
- 现场现象：[设备停、灯闪等]
- 最近变更：[是否做过修改]

## 要求
请分析：
1. 故障原因（按可能性排序）
2. 每个原因的判断依据
3. 排查步骤（从简到繁）
4. 解决方案
5. 预防措施

按以下格式输出：

### 🔍 故障分析

#### 原因 1（可能性最高）
- **判断依据**：...
- **排查步骤**：
  1. 检查...
  2. 确认...
- **解决方案**：...

#### 原因 2
...

### 📋 排查清单
- [ ] 检查电源
- [ ] 检查连接
...

### ⚠️ 注意事项
- 涉及安全回路的操作必须...
```

## 注意事项
- 涉及安全回路的故障，必须先隔离再排查
- 修改程序前必须备份
