# 工程工具

## 工具链
| 工具 | 用途 | 说明 |
|---|---|---|
| Wireshark | 网络分析 | 抓包、协议解码 |
| TcPcap | 流量分析 | 工业协议流量分析 |
| Modbus Poll | 协议测试 | Modbus 主站模拟 |
| Modbus Slave | 协议测试 | Modbus 从站模拟 |
| Plcopen | 编程规范 | IEC 61131-3 标准实现 |

## 使用笔记
- **Wireshark**: 过滤器语法、列添加、导出功能
- **TcPcap**: 流量分析、协议解码
- **Modbus 测试**: 点表验证、读写测试

> 工具按使用频率排序，记录配置方法和常见问题。
