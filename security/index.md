# OT 安全实践笔记

## 网络分段与 Purdue 模型

### Purdue 模型（5 级）

| 级别 | 名称 | 说明 |
|---|---|---|
| Level 0 | 企业网络 | IT 网络，办公、邮件、Web |
| Level 1 | 控制网络 | SCADA 监控，报表、统计 |
| Level 2 | 现场网络 | PLC 控制，现场仪表盘 |
| Level 3 | 现场仪表 | 传感器、执行机构 |
| Level 4 | 现场过程 | 物理过程、生产线 |

### 分段原则

- **默认拒绝**：只允许必要通信
- **单向通信**：数据单向流动（如监控数据上行，控制命令下行）
- **DMZ**：隔离区，外部访问只能到达 DMZ
- **防火墙**：应用层防火墙，工业协议检测

## 身份与权限管理

### RBAC（基于角色的访问控制）

| 角色 | 权限 | 说明 |
|---|---|---|
| Viewer | 只读 | 查看数据、报表 |
| Operator | 读+操作 | 操作设备、下发命令 |
| Engineer | 读+操作+配置 | 配置参数、修改程序 |
| Administrator | 全权 | 系统配置、用户管理 |

### 最小权限原则

- 用户只拥有完成工作所需的最小权限
- 临时权限：审批后授予，到期自动撤销
- 分离职责：关键操作需要多人确认

### 多因子认证（MFA）

- 密码 + 硬件令牌
- 密码 + 生物识别
- 密码 + 一次性密码（OTP）

## 补丁管理

### 工业补丁特点

- **测试环境**：先在非生产环境测试
- **备份**：补丁前备份系统配置
- **维护窗口**：计划内的停机时间补丁
- **回滚方案**：补丁失败时的回滚计划

### 补丁流程

1. 识别补丁需求
2. 获取补丁（供应商、CVE 数据库）
3. 测试补丁（非生产环境）
4. 计划部署（维护窗口）
5. 备份系统
6. 应用补丁
7. 验证补丁
8. 记录与报告

## 威胁检测

### IDS/IPS

- **Snort**：开源入侵检测/防御系统，支持工业协议规则
- **Suricata**：开源 IDS/IPS，多线程，支持多种协议
- **工业协议规则**：Modbus、DNP3、OPC UA、S7 等协议的检测规则

### 日志分析

- **Syslog**：集中日志记录
- **SIEM**：安全信息与事件管理（Splunk、Elastic SIEM 等）
- **事件关联**：多源日志关联，发现攻击模式

### 威胁模型

- **STRIDE**：具体、可复制、完整、访问控制、保密性、完整性、可用性
- **PASTA**：过程、分析、场景、威胁、影响、行动
- **ATT&CK for ICS**：针对工业控制系统的攻击框架

## 事件响应

### 响应流程

1. **检测**：发现安全事件（告警、日志、监控）
2. **分析**：确认事件性质、范围、影响
3. **遏制**：隔离受影响系统，防止扩散
4. **清除**：移除威胁，修复漏洞
5. **恢复**：恢复系统正常运行
6. **回顾**：事后分析，改进防护

### 取证工具

- **Wireshark**：网络包捕获与分析
- **tcpdump**：命令行包捕获
- **Volatility**：内存取证
- **SANS DFIR Toolkit**：取证工具包
- **Autopsy**：文件系统取证

## 实践建议

### 网络安全

- 使用 VPN 进行远程访问
- 禁用未使用的端口和服务
- 定期审计防火墙规则
- 使用加密通信（SSL/TLS、SSH）

### 系统安全

- 定期修补操作系统和应用程序
- 禁用默认账号和密码
- 限制远程访问（只允许必要 IP）
- 启用审计日志并定期审查

### 人员安全

- 安全培训与意识提升
- 定期进行钓鱼攻击模拟
- 建立安全文化和流程
